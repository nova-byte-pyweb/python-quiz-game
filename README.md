# Python Quiz Game

An interactive command-line quiz game built with Python.

## Features

- Randomized question order
- Multiple-choice questions (A/B/C/D)
- Instant feedback for each answer
- Final score calculation
- Performance messages based on score
- Covers technology, science, geography, sports, and general knowledge

## Technologies

- Python 3
